# Budget-Dashboard 
Ghost Budget Dashboard

Thank you for purchasing!

To use:
1. Open the folder.
2. Double-click index.html.
3. Add your income, bills, and expenses.
4. Your entries save automatically in your browser.
5. Use the Print Dashboard button to print or save as PDF.
6. Use Export CSV to download your transaction list.

Important:
This dashboard stores data locally in your browser. It does not upload your data anywhere.
